# Patches

Series of patches giving the MGIS of the prototype from MGIS master, commit
`818f0f9` (02/10/2026):

```bash
git clone <official MGIS repository> mgis && cd mgis
git checkout 818f0f9
git am /path/to/patches/*.patch
```

Patches:

1. loading of the behaviours generated by the `generic-parallel` interface
   of MFront: interface and backend of a behaviour, version of the data
   structures, pointers to the batch functions, refusal of the functions of
   a point for those behaviours (and conversely), copies of the data
   structures;
2. integration of a batch from a material data manager, without copy,
   automatic switch of the integration functions, execution policy, no
   unloading of the libraries at the end of the process (threads of TBB);
3. initialize functions and post-processings of batches;
4. fix of the checks of the material axes of the rotation matrices;
5. rotations of batches;
6. uniform material properties given by a span (the only way to give a
   uniform value in memory accessible by a device);
7. tests of the behaviours generated with the `cuda` backend, the data
   being allocated in managed memory by the calling code;
8. location of the arrays of a material data manager (host, device,
   shared), checked against the backend and the functions working on the
   host;
9. test of the batch rotations of finite strain behaviours.
