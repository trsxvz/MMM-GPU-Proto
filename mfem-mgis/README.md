MFEM/MGIS is a C++ library for nonlinear thermo-mechanical simulations on HPC
systems, combining [`MFEM`](https://mfem.org/) finite elements and
[`MFront`](https://thelfer.github.io/tfel/web/index.html) behaviours through
[`MGIS`](https://github.com/thelfer/MFrontGenericInterfaceSupport).

This branch is a prototype in which the finite element computations, the
integration of the behaviours, the linear solvers and the post-processings
can run on GPUs, placed by the option `--execution cpu|gpu|mixed` (see
[Computations by batches and by kernels](docs/source/user_guide/batch_computations.rst)).
CUDA is tested; HIP compiles but has not been run on an AMD GPU yet. These
features are not available in the `master` branch nor in the releases.

The goal and features of MFEM/MGIS are described in its
[JOSS paper](https://doi.org/10.21105/joss.07719).
